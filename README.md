# EinthuTv

Android TV app that opens einthusan.tv in a remote-friendly, full-screen shell.

## Features
- Home screen with quick launch for 8 languages
- D-pad navigation with a visible focus ring
- Pointer mode (press **MENU**) for menus the D-pad can't reach
- Full-screen video, media keys (play/pause, FF +30s, RW −10s)
- Stays signed in (cookies kept)
- Blocks pop-up windows and redirects to other sites

## Remote controls
| Button | Action |
|---|---|
| Arrows / OK | Navigate and select |
| Hold OK (1 sec) or MENU | Toggle pointer mode |
| BACK | Exit full screen → page back → home (press twice) |

## Build
Push to `main` on GitHub. The **Build APK** workflow builds `EinthuTv.apk` and attaches it to a new Release.
